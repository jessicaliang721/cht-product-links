# CHT Product Links

The public product catalog for [@cozyhobbytime](https://www.youtube.com/@cozyhobbytime) — the notebooks, pens, craft supplies, desk gear, and everyday tools I use and recommend.

**Live site:** https://jessicaliang721.github.io/cht-product-links/

## About

A single static page: search, category filters, and shareable deep links.

- `?category=Pens%20%26%20ink` — open with a category pre-selected
- `?q=hobonichi` — open with a search pre-filled
- `?product=63` — open scrolled to one product, highlighted

Read-only for visitors. Product data lives in the `products` array in `index.html`; images live in `assets/`.
